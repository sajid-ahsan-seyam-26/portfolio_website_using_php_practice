## Requirements

To run this project, you need:

- XAMPP or any local server
- PHP installed
- Web browser

## How to Run

### Step 1

Open XAMPP and start **Apache**.

### Step 2

Copy your project folder into:

```bash
C:\xampp\htdocs\

Example folder:

C:\xampp\htdocs\simple_php_project\
Step 3

Open browser and go to:

http://localhost/simple_php_project/login.php
```
